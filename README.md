# 🐍 Snake, Water, Gun Game

A simple command-line game developed using Python. The player competes against the computer, which randomly selects Snake, Water, or Gun.

## 🚀 Features

* Random computer choices using Python's `random` module.
* User input for selecting Snake, Water, or Gun.
* Automatic winner determination.
* Draw detection.
* Simple command-line interface.

## 🛠️ Technologies Used

* Python
* Random module
* Dictionaries
* Conditional statements
* User input and output

## 🎮 How to Play

1. Clone or download this repository.

2. Make sure Python is installed on your computer.

3. Open a terminal in the project folder.

4. Run the following command:

   ```bash
   python snake_water_gun.py
   ```

5. Enter your choice:

   * `s` — Snake
   * `w` — Water
   * `g` — Gun

6. The computer randomly selects its choice, and the game announces the winner.
